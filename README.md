# 建设工程合同模板与审查

> 建工领域合同模板库、审查要点与风险提示

## 项目简介

本项目建设工程合同模板与审查工具库，面向建设工程领域的法律实务需求，涵盖：

- **施工合同** — 建设工程施工合同模板及审查要点
- **设计合同** — 建设工程设计合同模板及审查要点
- **监理合同** — 建设工程监理合同模板及审查要点
- **审查清单** — 合同审查逐项检查清单
- **实务指南** — 合同谈判与风险控制指南

## 目录结构

```
construction-law/
├── templates/              # 合同模板
│   ├── construction/       # 施工合同
│   ├── design/            # 设计合同
│   └── supervision/       # 监理合同
├── review/                 # 审查工具
│   ├── checklists/         # 审查清单
│   └── guides/             # 实务指南
├── references/             # 参考资料
│   ├── laws/              # 法律法规
│   ├── regulations/        # 部门规章/司法解释
│   └── standards/          # 行业标准/规范
├── docs/                   # 项目文档
└── examples/               # 示例案例
```

## 主要法律依据

- 《中华人民共和国民法典》第三编 合同编
- 《中华人民共和国建筑法》
- 《中华人民共和国招标投标法》
- 最高人民法院《关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》（法释〔2020〕25号）
- GF-2020-0201 建设工程施工合同（示范文本）

## 使用说明

1. 在 `templates/` 目录下查找对应合同类型的模板
2. 使用 `review/checklists/` 中的清单逐项审查
3. 参考 `review/guides/` 中的指南识别风险条款
4. 在 `references/` 中查阅相关法律依据
