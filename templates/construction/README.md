# 施工合同模板

## 模板说明

本目录包含建设工程施工合同相关模板，基于 GF-2020-0201 示范文本整理，结合实务经验增补风险条款提示。

## 文件清单

| 文件名 | 说明 |
|--------|------|
| `施工合同-通用版.md` | 建设工程施工合同通用模板 |
| `施工合同-固定总价.md` | 固定总价合同专用模板 |
| `施工合同-风险条款对照表.md` | 合同条款与法律风险对照 |

## 审查要点

### 一、合同主体审查
- 发包人：核实营业执照、资质证书、建设用地规划许可证、建设工程规划许可证
- 承包人：核实营业执照、资质证书、安全生产许可证（是否在有效期内）

### 二、工程范围与工期
- 明确工程范围界定（避免"详见附件"模糊表述）
- 开工日期、竣工日期、工期总天数
- 工期延误的违约责任与顺延条件

### 三、合同价款
- 计价方式：固定总价 / 固定单价 / 可调价
- 工程款支付节点与比例
- 进度款申报、审核、支付期限
- 竣工结算期限与程序
- 质量保证金比例与返还期限

### 四、工程质量
- 质量标准（国标/行标/企标）
- 验收程序与标准
- 质量缺陷修复责任与期限

### 五、风险条款重点
- ⚠️ **背靠背条款**：发包人约定"待收到业主付款后再向承包人支付"——需审查是否有效
- ⚠️ **逾期竣工违约金**：关注违约金比例是否过高（一般不超过合同价款的 3%-5%）
- ⚠️ **不可抗力条款**：明确约定不可抗力范围及通知义务
- ⚠️ **合同解除权**：双方解除权的行使条件与程序
- ⚠️ **争议解决条款**：约定管辖法院或仲裁机构
