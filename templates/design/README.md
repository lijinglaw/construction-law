# 设计合同模板

## 模板说明

本目录包含建设工程设计合同相关模板，涵盖方案设计、初步设计、施工图设计等阶段。

## 文件清单

| 文件名 | 说明 |
|--------|------|
| `设计合同-通用版.md` | 建设工程设计合同通用模板 |

## 审查要点

### 一、设计阶段与成果
- 方案设计 / 初步设计 / 施工图设计（明确约定交付阶段）
- 设计成果的内容、深度、格式要求
- 设计修改与返工的责任划分

### 二、设计费用
- 计费标准（按投资额比例 / 按面积 / 固定费）
- 支付节点与比例
- 设计变更导致的费用调整机制

### 三、设计责任
- 设计质量标准与验收标准
- 设计缺陷造成的损失赔偿责任
- 责任限额约定
