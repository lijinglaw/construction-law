# 参考资料

建设工程合同实务常用法律依据，内容来源于[国家法律法规数据库](https://flk.npc.gov.cn)（经 [LawRefBook/Laws](https://github.com/LawRefBook/Laws) 项目整理）。

依据《中华人民共和国著作权法》第五条，法律、法规及司法解释等具有立法、行政、司法性质的文件不适用著作权法，属于公有领域。

## 使用建议

1. 审查施工合同时，优先对照「建工司法解释一」与民法典合同编第十八章
2. 涉及招投标程序的合同效力问题，查招标投标法及其实施条例
3. 质量、安全、勘察设计类违约争议，查对应行政法规
