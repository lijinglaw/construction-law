## 一、合同主体（□通过 / □需修改 / □不通过）

- [ ] 发包人具备发包主体资格
- [ ] 承包人具备相应施工资质（核实资质等级、有效期）
- [ ] 承包人具备安全生产许可证（核实有效期）
- [ ] 项目经理具备注册建造师资格
- [ ] 双方联系人、通讯地址明确

## 二、工程范围（□通过 / □需修改 / □不通过）

- [ ] 工程名称、地点明确
- [ ] 工程内容描述清晰（非仅"详见附件"等模糊表述）
- [ ] 承包范围边界明确
- [ ] 与招标文件/投标文件一致（如为招标项目）

## 三、工期条款（□通过 / □需修改 / □不通过）

- [ ] 开工日期明确（非"以开工令为准"等模糊表述）
- [ ] 竣工日期明确
- [ ] 工期总天数与开竣工日期一致
- [ ] 工期顺延条件明确
- [ ] 工期顺延程序明确（通知期限、确认方式）
- [ ] 逾期竣工违约金合理（日万分之三至五，有上限）
- [ ] 发包人原因延误的补偿条款

## 四、合同价款（□通过 / □需修改 / □不通过）

- [ ] 计价方式明确（固定总价/单价/可调价）
- [ ] 合同价款构成清晰
- [ ] 预付款比例、支付时间、扣回方式
- [ ] 进度款申报周期、审核期限、支付期限
- [ ] 竣工结算程序与期限
- [ ] 质量保证金比例不超过3%
- [ ] 质量保证金返还期限
- [ ] 价格调整因素与调整方法（如可调价合同）

## 五、工程质量（□通过 / □需修改 / □不通过）

- [ ] 质量标准明确（具体国标/行标编号）
- [ ] 隐蔽工程验收程序
- [ ] 分部分项验收程序
- [ ] 竣工验收程序
- [ ] 质量缺陷通知与修复期限
- [ ] 缺陷责任期（不超过2年）

## 六、材料设备（□通过 / □需修改 / □不通过）

- [ ] 发包人供应材料/设备的，交货时间、地点、验收方式
- [ ] 承包人采购材料/设备的，质量要求、品牌范围
- [ ] 材料价格确认机制

## 七、工程变更（□通过 / □需修改 / □不通过）

- [ ] 变更提出方式与程序
- [ ] 变更价款确定方法
- [ ] 变更签证要求（书面签证）

## 八、合同解除（□通过 / □需修改 / □不通过）

- [ ] 双方解除权条件对等
- [ ] 解除后的结算方式
- [ ] 解除后的工程移交程序
- [ ] 不存在明显不对等的单方解除条款

## 九、违约责任（□通过 / □需修改 / □不通过）

- [ ] 违约金条款对等
- [ ] 违约金比例合理
- [ ] 损失赔偿范围明确
- [ ] 不存在免除一方主要责任的格式条款

## 十、争议解决（□通过 / □需修改 / □不通过）

- [ ] 管辖约定明确（法院或仲裁，二选一）
- [ ] 如约定法院管辖，管辖法院有利于己方
- [ ] 如约定仲裁，仲裁机构名称准确

## 十一、其他条款（□通过 / □需修改 / □不通过）

- [ ] 不可抗力条款完整
- [ ] 保密条款
- [ ] 知识产权条款
- [ ] 通知条款（送达地址、方式）
- [ ] 附件完整且与正文一致
